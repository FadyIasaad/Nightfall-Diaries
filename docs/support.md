# Nightfall Diaries — Support

The automation is currently owner-only and pre-production. Public consumer accounts are not offered.

**For ordinary, non-sensitive bug reports:** use the repository's [Issues page](https://github.com/FadyIasaad/Nightfall-Diaries/issues).

**For confidential OAuth, account-access, privacy or deletion requests:** do **not** use public Issues or paste credentials in chat. **A verified private support email/contact must be supplied by the owner before the policy website is submitted to any platform review.** No confidential contact channel is asserted here yet.

### Owner acceptance checklist
- [ ] Choose and publish a working private support address or ticketing channel.
- [ ] Confirm the intended data controller / operator description and applicable jurisdiction.
- [ ] Verify privacy and terms accurately match any real tokens, storage and processing.
- [ ] Enable GitHub Pages from `main` / `docs`, then open each live URL.
- [ ] Submit only *verified* live policy URLs to provider app-review forms.
