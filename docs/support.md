# Nightfall Diaries — Support

The automation is currently owner-only and pre-production. Public consumer accounts are not offered.

**For ordinary, non-sensitive bug reports:** use the repository's [Issues page](https://github.com/FadyIasaad/Nightfall-Diaries/issues).

**For confidential OAuth, account-access, privacy or deletion requests:** do **not** use public Issues or paste credentials in chat. Contact Nightfall Diaries directly by email at either address:

- **fadyasaad.kaz@gmail.com**
- **fadyasaad13@gmail.com**

These are public support contact options supplied by the project owner. The inboxes have not been independently tested; please do not include passwords, access tokens, secret keys or sensitive identity documents in your message.

- [x] List owner-provided support email addresses in the public policy documents (inbox delivery not independently verified).
- [ ] Verify both inboxes receive incoming support messages.
- [ ] Confirm the intended data controller / operator description and applicable jurisdiction.
