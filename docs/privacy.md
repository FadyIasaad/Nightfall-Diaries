# Nightfall Diaries — Privacy Policy

**Last updated:** November 5, 2026  
**Status:** Draft for an owner-operated service; requires owner contact and factual approval before an app review submission.

Nightfall Diaries creates and, after owner approval and successful platform authorization, may distribute original AI-assisted animated videos to the project owner's YouTube, Facebook Page, Instagram and TikTok accounts. At present the automatic publication system is in development.

## What information we handle
The app is intended for **the owner's own authorized accounts**, not a consumer sign-up service. When the owner connects a supported platform, the workflow may process account identifiers, access and refresh tokens, and upload/processing identifiers necessary to manage the owner's own videos. We do not request passwords, collect payment information or ask the owner to paste credentials into public files.

If someone opens public pages, GitHub Pages or other underlying hosting/platform providers may process technical connection information under their own privacy policies. Nightfall Diaries does not currently operate a separate visitor analytics or advertising service.

## Purposes
Account connection, producing original video content, uploading only to accounts the owner authorized, querying processing/publication statuses, preventing duplicate posting, security diagnostics and troubleshooting failures. Provider-specific requests are governed by the relevant platform's policies.

## Storage and sharing
Access tokens are intended to remain in **GitHub Actions repository secrets**, not repository source code, GitHub Pages, reports, logs or media assets. Non-secret episode IDs, generation artifacts and upload-status receipts may be kept in GitHub Actions caches, run artifacts, repository metadata or, after separate approval, Kaggle datasets. The public repository and public release assets are visible to others. Only the minimum necessary account data should be transmitted to GitHub, YouTube/Google, Meta, TikTok, Hugging Face, Kaggle or other explicitly approved providers to perform a requested action.

We do not sell personal information or share it with advertisers.

## Retention
Workflow artifacts and caches are subject to GitHub's retention and eviction policies. Authorized platform records are retained according to each platform's policies. A production retention/deletion schedule must be finalized **before collecting data from anyone beyond the owner**. We will not claim permanent secure storage or immediate deletion from external providers.

## Control and deletion
The owner can disconnect/revoke provider tokens at the issuing platform and remove GitHub secrets. To ask about personal information, access or deletion, use the support method stated on the [support page](support.md). **Never post tokens, IDs, sensitive information or personal details in a public GitHub issue.**

## Children and sensitive data
The app is not designed to collect children's personal information, other users' credentials or sensitive personal records. It does not offer a user-account registration feature.

## Changes
We may update this policy if supported providers, storage or processing change; the new date will appear here. Changes should be reviewed before platform audit submission or public production use.
