# Nightfall Diaries automatic production policy

Do not ask the owner to approve each cast member, image or voice.
Normal production must create reusable character reference sheets, stable voices, animated story-directed shots, captions, soundtrack, and edited vertical MP4 automatically, checking failures and retrying.

Owner approval only at:
1. The first REAL 10-15-second cinematic MP4 quality gate; lock the resulting production standards for later episodes.
2. The selection of the next original series when a finished season is confirmed published, with 3-5 ChatGPT proposals.

Once the reference-quality generation method is working and publishing credentials are tested, generate and post authorized episodes to existing YouTube, Facebook, Instagram and TikTok destinations, then record confirmed public receipts. No advancement for rendered or draft-only episodes.

STATUS: This repository currently generates validated scripts and an automatic machine-readable PREPRODUCTION pack with character, voice and scene requests. It DOES NOT create images, synthesize voices, render video or publish yet. A cloud AI-video provider must be tested, connected and shown to meet the reference quality. Do not start a daily schedule until those blockers are resolved. Never mistake a green Action for a good video.

The user's approved Ember image is a visual direction from chat; its actual file is not yet preserved as a locked repository asset. Do not repeat individual character approval questions.

New series always require owner choice; the existing ChatGPT season-end monitor is a separate notification service.
